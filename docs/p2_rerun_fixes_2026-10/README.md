# P2 truncated-run fixes (2026-10-22)

**Scope.** An audit found truncated training runs feeding P2 numbers. This folder holds the full
completeness sweep, the resumes, the gated held-out-LOSO regeneration and the recomputed derived statistics.
Nothing here edits a paper `.tex` file or commits.

**Status: all reruns are finished.** Every P2-linked run that P2 still uses now reaches its final epoch.
Two exceptions are not rerun on purpose: the old-recipe (lr 0.01) Adaptive GNN and Attention GNN LOSO runs,
which are superseded by lr 0.1, and the diverged SLGTFormer lr-0.1 LR-sweep run.

## Contents

- `incomplete_runs.md`: the sweep after the fixes. It is regenerated by
  `python tools/check_run_complete.py --p2-sweep --md docs/p2_rerun_fixes_2026-10/incomplete_runs.md`.
- `raw/incomplete_runs_prefix_snapshot_0501.md`: the sweep before the fixes (05:01, before any job). Its
  `NO_CONFIG` rows for `*_lr01_seed*_test` and `*_clip5_seed*_test` were false alarms from an earlier version
  of the tool. Those are score-only dirs, and their parents are complete.
- `jobids.txt`: every job ID. Other agents also append here.
- `raw/p2_make_tables_*`: table `--check` and `--dry-run` captures before and after.

## Tools (new or changed, uncommitted)

| file | what |
|---|---|
| `tools/check_run_complete.py` | **New.** Rule: a run is complete when `max("Eval epoch") == num_epoch` of the run's own saved `config.yaml`, or when the final-epoch checkpoint exists. `--phase test` dirs are traced through `Load weights from` and flagged when (a) the parent is incomplete, (b) the scored checkpoint is not the best-val epoch, or (c) the dump is stale. `--p2-sweep` lists P2-linked runs from the `tools/p2_make_tables.py` SPEC, the LOSO CSVs, the tab:sig dumps, the baseline runs and the prose families. `--loso-csv` checks per-cell completeness and staleness (`model-best.pt` newer than the CSV). Read errors are fatal. |
| `tools/loso_heldout_eval.py` + `scripts/hpc/slurm_loso_heldout_allarch_v2.sbatch` | **Gated held-out LOSO evaluator (v2).** It uses the same scoring as v1 (`tools/eval_ckpt_on_npy.py`), the same CSV format and the same row order. It refuses to write unless all 33 fold runs are complete, and it also refuses on state-dict mismatch or a missing bundle. It backs up the old CSV once as `*.pre_fix_2026-10-22.csv`. |
| `tools/p2_rerun_fixes_tasks.py`, `scripts/hpc/slurm_p2_rerun_fixes.sbatch`, `scripts/hpc/p2_rerun_fixes/` | Task lists, configs (`config/p2_rerun_fixes/`, rebuilt from each run's own saved config) and an 8-h-chunk lane runner. The runner is a copy of the lr0p1 runner, with 1 SLGTFormer per GPU. |
| `tools/p2_rerun_fixes_derived.py` | Rebuilds `heldout_as_results_blockgcn_lr01.csv`, `variance_decomp_blockgcn_lr01.txt` and `arch_significance_blockgcn_lr01{,_twosided}.txt`, plus a `bestck` variant. Old files are kept as `*.pre_fix_2026-10-22.*`. |
| `tools/arch_significance.py` | Adds `--two-sided`: p2 = min(1, 2p), computed from the same bootstrap draws, with Holm within each family. The default output is byte-identical to before. Adds `--bestck`. |
| `tools/p2_make_tables.py` | Adds `bestck` recipes for SLGTFormer, GNN+LSTM, Pose-LSTM and ST-GCN. The P2 rewrite agent has since made them active. |

### New finding: Protocol-A TEST used non-best checkpoints

P2 App. "Evaluation" says the best-val checkpoint is scored on TEST. For runs that predate `*_model-best.pt`,
the `_test` dumps instead scored whatever per-epoch checkpoint was kept:

| run | scored | best-val epoch |
|---|---|---|
| SLGTFormer s0 | ep80, val 85.80 | ep95, val 86.87 |
| SLGTFormer s1 | ep70, val 88.09 | ep75, val 89.31 |
| SLGTFormer s2 | ep20 of a truncated run | — |
| GNN+LSTM s0 | ep80 | ep85 |
| GNN+LSTM s2 | ep40 | ep75 |
| Pose-LSTM s1 | ep90 | ep85 |
| Pose-LSTM s2 | ep90 | ep55 |
| ST-GCN s2 | ep100 | ep55 |
| Adaptive GNN s1 (lr 0.01) | ep60 | ep45 |
| Attention GNN s2 (lr 0.01) | ep60 | ep65 |
| GNN+T unclipped s1 | — | — |

The adaptive/attention/unclipped rows are superseded and not fixed.

**Fix (stems `bdsl_<arch>_si_bestck`).** The best-epoch weights were never saved, so the affected seeds were
re-trained from scratch with the identical config. Unaffected seeds were re-scored from their original checkpoint.
Those re-scores reproduce the old TEST exactly (75.16, 62.49, 75.02, 74.07), which confirms the eval path.

- Fresh retrains: SLGTFormer s0 (job) and s1 (<job>); GNN+LSTM s0 and s2, Pose-LSTM s1 and s2, ST-GCN s2 (<job>).
- SLGTFormer s2 uses its resumed `model-best.pt`.

The P2 rewrite agent has already adopted the `bestck` stems as the active recipe.
