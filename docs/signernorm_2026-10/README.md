# Signer-normalized pose recipe (P2, BdSLW60 signer-independent), 2026-10-22

This is a label-free input recipe meant to shrink the unseen-signer gap. It changes only the feeder; the
models are untouched except for `in_channels` 3→5 when the hand-local channels are on.

- Protocol A: train on 8 signers, select the checkpoint on val U15, report held-out TEST (U02, U13; 1,365 clips).
- 3 seeds. ± is the population SD over seeds, the same convention as docs/blockgcn_lr01_switch.
- Nothing here edits the paper `.tex`, and nothing is committed.

The recipe components. Order of operations inside the feeder: window → d → c → b (taken from image coordinates) → a / ctr → random_shift.

- **ctr (control)** (`body_frame: True, body_scale: none`): centres each frame on the shoulder midpoint, with no scaling. Padded frames and undetected joints stay exactly 0.
  - This isolates the fix for an artefact in Feeder's `normalization`. Feeder subtracts the node-0 mean over the 120-frame window *including zero padding*, then subtracts it from every entry, so padding and undetected joints become non-zero constants.
- **(a) body frame** (`body_frame: True`): per-frame centring on the shoulder midpoint plus scaling by shoulder width.
  - Frames without shoulders borrow the nearest valid frame. (In BdSLW60 the shoulders are present in every non-padded frame.)
  - (a) *replaces* Feeder's centring, so **part of any (a) gain is the centring-artefact fix rather than signer normalization**. The ctr row measures that part.
- **(b) hand-local channels** (`hand_local: True`): 2 extra channels holding wrist-relative hand coordinates divided by palm size (the clip median of the max wrist→MCP distance). This changes C from 3 to 5 and keeps the (N,C,T,V,M) contract. All 8 archs build their input layers from `in_channels`, and a forward/backward pass was checked for each one.
- **(c) mirror** (`random_mirror: True, p 0.5`): Feeder's own transform (`flip_index` + x→1−x), train only.
- **(d) cross-signer bone retargeting** (`bone_aug: signer, p 0.5`): rescales 23 bones along a kinematic tree rooted at the shoulder midpoint to a random *other* training signer's mean bone lengths.
  - The bone vector is scaled by L_target/L_source using signer means in shoulder-width units, so per-frame foreshortening is kept.
  - Signer/global ratios span 0.71–1.33; forearms vary most.
  - `bone_aug: jitter` is the simpler U(1±s) fallback.
- **oracle handedness** (`oracle_hand_canon: True`): **uses filename metadata (`_L`/`_R`) and is not deployable.** It mirrors `_L` clips to right-hand at train and test, and serves as an upper bound for handedness canonicalization.

## 2. Unit tests

`pytest tests/test_feeder_signernorm.py`: **18 passed**. The real-clip tests use 64 clips spread over the SI train file. They cover:

- all options off gives the same output as `Feeder` under the same RNG;
- shapes (3 or 5 channels) are right, all values are finite, and padded frames and missing points stay 0, for 7 option combinations;
- mirror applied twice is the identity, and `flip_index` is an involution and a graph automorphism of `graph.sign_27`;
- the body frame and hand-local channels are invariant to global scale and translation (frame and clip modes), and in frame mode the shoulder width comes out at 1;
- the nearest-frame fallback works, and a clip with no shoulders still gives finite output;
- retargeting with all scales at 1 is the identity, and each bone comes out at scale × its original length (shoulders and visibility untouched);
- signer bone statistics are finite and positive;
- the centring-only control is translation-invariant and unscaled;
- oracle canonicalization mirrors exactly the `_L` clips;
- BlockGCN accepts 5 channels.

## 3. flip_index verdict: **correct**; the published mirror numbers are not affected

The node order comes from `preprocessing/preprocess_bdsl.py` (MediaPipe Holistic, subject's own left/right):

| nodes | content |
|---|---|
| 0 | nose |
| 1 / 2 | R / L shoulder |
| 3 / 4 | R / L elbow |
| 5 / 6 | R / L wrist |
| 7–16 | `right_hand_landmarks` |
| 17–26 | `left_hand_landmarks` |

The data agrees: pose R-wrist (5) sits 0.026 from node 7 versus 0.296 from node 17, and node 6 behaves the same way with 17. The graph edges (5,7) and (6,17) agree too, as does the image position (R shoulder at x≈0.37, image-left, unmirrored video).

`flip_index` swaps 1↔2, 3↔4, 5↔6 and 7–16↔17–26. Both hands share the same landmark order, and the swap maps every graph edge onto an edge (tested). x→1−x is correct for normalized coordinates. **The P2 mirror results (BlockGCN +7.6, SLGTFormer +8.0) stand.**

The mislabel the earlier audit saw is cosmetic. The comment in `feeders/feeder.py` and the `_KP_GROUPS` names `left_hand`=7–16 / `right_hand`=17–26 are swapped: 7–16 is the *right* hand. This only matters if a `keypoint_drop: left_hand/right_hand` result is ever reported by hand name. Hands-only and body-only are unaffected.

### Honest decomposition (successive Δ, TEST mean)

| step | Δ | reading |
|---|--:|---|
| Feeder centring → shoulder-midpoint centring, padding and missing kept at 0 (**ctr**) | **+3.7** | An artefact fix, not signer normalization. It comes entirely from U02 (+9.4 ensemble); U13 is unchanged. |
| ctr → +a (add shoulder-width scaling) | **−0.5** | Scale normalization adds nothing beyond centring, within seed SD. |
| +a → +a+b (hand-local channels) | **+4.7** | The largest *signer-normalizing* contribution; it helps both signers. |
| +a+b → +a+b+c (mirror) | **+4.0** | A handedness effect (below), consistent with P2's mirror ablation (+7.6 on the raw recipe). |
| +a+b+c → +a+b+c+d (bone retargeting) | **+0.7** | Not significant: within seed SD (1.1–1.5), and the ensemble is *identical* (83.22, Δ ens 0.00). |

### Recipe chosen for Stage 2: **a+b+c** (decided before any Stage-2 run)

- **Pre-stated Stage-2 rule:** Stage 2 runs only if the best recipe beats the baseline by more than the seed SD. It does: the best is +12.55 against a baseline SD of 0.56 and a recipe SD of about 1.5.
- **Choosing among recipes:** val cannot distinguish ab, abc and abcd (all within SD). abcd vs abc is within seed SD on TEST as well (+0.7, identical ensemble), so the **simpler abc** is chosen.
- **Basis for including c:** P2's existing, independent mirror ablation, plus the handedness mechanism above. It is not the Stage-1 TEST ranking. That said, the P2 mirror ablation is itself a TEST measurement: there is no val-only justification for c, because U15 is almost entirely right-handed.

## 7. Recommendation

**Adopt it as a P2 method subsection, with an honest decomposition rather than a "signer normalization" headline.**

Why it qualifies:
- It is label-free and touches only the feeder.
- It was chosen on Stage 1 before any Stage 2 run.
- It improves every one of the 8 pose archs by +5.9 to +19.3 pp on held-out TEST.
- It shrinks the SMG by 6–17 pp per arch.
- It raises BlockGCN LOSO by +8.1 pp [+4.3, +12.6], with 10/11 signers improving and the hardest signer +25.7.
- It cuts class-conditioned signer leakage by about 20%.

What must be stated plainly:
1. **+3.7 pp of the BlockGCN gain is a bug fix in P2's own feeder.** The centring includes zero padding and makes padding and undetected joints non-zero; the ctr row isolates this.
2. **Shoulder-width scaling (a) adds nothing.**
3. **The real normalizing component is the hand-local channels (+4.7).**
4. **Mirror (+4.0) is a handedness effect.**
   - It acts on `_L` clips.
   - Validation cannot select it, because U15 has 3% `_L` clips vs 25% on TEST. Its inclusion rests on P2's mirror ablation and this mechanism.
   - It matches a metadata oracle.
5. **Bone retargeting is not significant.**
6. **The SMG remains +13–18 pp and leakage remains well above 0.** This is a partial fix, which supports, rather than undercuts, P2's benchmark thesis.

Also required in P2 (and done here):
- The leaderboard compresses (17.6 → 5.6 pp spread), so arch rankings under the old feeder partly reflect input-pipeline sensitivity.
- The Limitations centring sentence should point to this fix.
