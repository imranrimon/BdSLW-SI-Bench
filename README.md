# BdSLW-SI-Bench

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Python 3.8](https://img.shields.io/badge/python-3.8-blue.svg)](pyproject.toml)
[![CI](https://img.shields.io/badge/CI-GitHub%20Actions-lightgrey.svg)](.github/workflows/ci.yml)

A signer-independent benchmark for word-level Bangla sign language recognition.

Word-level Bangla sign recognition is usually evaluated on random splits in which every signer
appears in both training and test data. Under that protocol pose models score 94-99% Top-1 on
BdSLW60; when the test signers are unseen they score 61-79%. This repository provides the
protocol, the pose pipeline, eight re-implemented pose architectures plus RGB, foundation-model
and prior-method baselines, and the analysis code behind the paper (under review):

- **Splits.** A canonical signer-disjoint split of BdSLW60 (train signers 1, 4, 5, 6, 8, 9, 11,
  12; validation 15; test 2 and 13), 11 leave-one-signer-out (LOSO) folds, five matched-size
  signer-mixed splits, and a held-out-signer protocol for BdSLW401 (validation S15, test S04/S08).
- **Signer-Mixing Gap (SMG).** Accuracy on a matched-size signer-mixed split minus accuracy on
  unseen test signers: how much of a reported number is signer familiarity.
- **Pose pipeline.** MediaPipe Holistic, 27 keypoints (7 body + 10 per hand), with
  missing-joint-aware bones and cue perturbations; bundlers for BdSLW60, BdSLW401, AUTSL and
  ASL Citizen.
- **Signer-normalized input recipe.** A label-free feeder change (body frame, hand-local
  channels, mirroring) that adds 6-19 points of unseen-signer accuracy across all eight pose
  architectures.
- **Reproducible tables.** Every generated table cell traces to a result file; the published
  tables are regenerated and checked cell by cell from the files in `results/` and `docs/`.

## Key results

BdSLW60, Protocol A: train on 8 signers, select on validation signer 15, report Top-1 on the
held-out TEST signers 2 and 13 (1,365 clips). Mean ± SD over 3 seeds; LOSO is the mean ± SD of
held-out-signer accuracy over the 11 folds. Generated by `tools/p2_make_tables.py` and
`tools/signernorm_make_tables.py` (`results/tables/reference/`).

| Model | TEST Top-1 | Mixed | SMG | LOSO | TEST, signer-normalized |
|---|--:|--:|--:|--:|--:|
| SLGTFormer | **78.54 ± 1.15** | 98.64 ± 0.09 | +20.10 | **80.1 ± 15.9** | 85.33 ± 1.03 |
| Adaptive GNN (CTR-GCN-style) | 77.05 ± 0.92 | 99.10 ± 0.03 | +22.05 | **80.1 ± 16.3** | **85.84 ± 0.59** |
| GNN + Transformer | 75.56 ± 1.26 | 99.00 ± 0.15 | +23.44 | 77.1 ± 16.3 | 82.96 ± 1.90 |
| ST-GCN | 74.82 ± 0.55 | 98.51 ± 0.17 | +23.69 | 78.6 ± 15.9 | 80.68 ± 1.50 |
| Attention GNN | 73.92 ± 0.39 | 97.95 ± 0.33 | +24.03 | 77.6 ± 16.2 | 84.47 ± 0.30 |
| GNN + Bi-LSTM | 70.60 ± 3.24 | 97.24 ± 0.21 | +26.64 | 73.6 ± 16.7 | 80.98 ± 0.54 |
| BlockGCN | 68.82 ± 0.56 | 97.98 ± 0.07 | +29.16 | 74.4 ± 16.1 | 80.63 ± 1.10 |
| Pose-LSTM | 60.98 ± 1.56 | 94.20 ± 0.54 | +33.22 | 68.7 ± 15.7 | 80.27 ± 0.87 |

Same split, other input families: VideoMAE ViT-B/16 (RGB) 80.93 ± 2.11, S3D (RGB)
74.73 ± 1.76, Uni-Sign fine-tuned (RTMPose-133) 83.61 ± 1.08, SHuBERT frozen probe 67.42 ± 0.19.
BdSLW401 (held-out TEST signers S04/S08): ST-GCN 86.05 ± 0.31, CTR-GCN 85.56 ± 0.29,
BlockGCN 80.86 ± 0.83. In the LOSO variance decomposition the held-out signer dominates
(SD 15.25 points) over architecture (3.63), signer × architecture (1.90) and seed (2.19).

## Installation

Python 3.8, PyTorch 2.x (CUDA 11.8 for training), PyTorch Geometric, timm, einops.

```bash
# GPU environment (conda env `bdsl_graph`)
conda env create -f environment.yml
conda activate bdsl_graph

# or pip, e.g. CPU only
pip install torch==2.4.1 torchvision==0.19.1 --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt

# pose extraction only (newest Python 3.8 wheel with the legacy Holistic API)
pip install --only-binary=:all: mediapipe==0.10.9
```

The repository runs from source: execute commands from the repository root.
`pyproject.toml` holds the metadata, optional extras and tool configuration.

## Data preparation

No video, pose data or checkpoints are distributed in this repository. Obtain the source
datasets from their owners and extract poses locally with the provided pipeline.

| Dataset | Source | Terms |
|---|---|---|
| BdSLW60 | https://www.kaggle.com/datasets/hasaniut/bdslw60videoclips | CC BY-NC-ND 4.0 |
| BdSLW401 | https://www.kaggle.com/datasets/hasanssl/bdslw401 | data-use agreement with the owners |
| AUTSL, ASL Citizen | their official distributions | their own licenses |

BdSLW60 is licensed CC BY-NC-ND 4.0; derived pose arrays are therefore not redistributed here.
The derived pose releases (BdSLW60-SI, BdSLW401-SI) are hosted separately, each with its own
Croissant file (`metadata/`) and the datasheet (`docs/DATASHEET.md`).

**BdSLW60 (signer-independent bundle).** MediaPipe runs once per clip and is cached; every
other split is re-bundled from the cache.

```bash
python preprocessing/generate_signer_split_npy.py \
    --dataset-root /path/to/BdSLW60 \
    --output-dir data/bdsl_si --cache-dir data/bdsl_cache --splits train val test
python tools/check_pose_geometry.py --npz-dir data/bdsl_cache --strict   # skeleton sanity check
```

`--dataset-root` is the folder with the 60 class sub-directories of `.mp4` clips. Output:
`data/bdsl_si/<split>_data.npy` of shape `(N, 3, 300, 27, 1)` (x, y, visibility; undetected
joints are 0) and `<split>_label.pkl` = `(clip_ids, labels)`. The split itself is fixed in
`splits/signer_independent.json` and `preprocessing/bdsl_signer_split.py`.

| Bundle | Command |
|---|---|
| Signer-mixed (Mixed, `data/bdsl_sd`) | `python preprocessing/generate_random_split_npy.py --pose-cache data/bdsl_cache --out-pose data/bdsl_sd --no-dino` |
| Matched random splits (`data/bdsl_rand4{2..6}`) | `python preprocessing/make_bdsl_random_split.py --seed 42 --out data/bdsl_rand42` (seeds 42-46) |
| One LOSO fold | `python preprocessing/generate_loso_split_bundle.py --cache-dir data/bdsl_cache --output-dir data/bdsl_si_loso/test_U02_val_U01 --test-signer 2 --val-signer 1` (`tools/run_loso.py` builds all folds) |
| Bone stream (missing-joint masked) | `python preprocessing/generate_bone_data_masked.py --data-dir data/bdsl_si --output-dir data/bdsl_si_bonemask` |
| Cue perturbations | `preprocessing/make_cue_bundle_masked.py`, `preprocessing/make_cue_bundle.py` |
| Paired SMG, signer grid, k-shot | `preprocessing/generate_paired_smg_bundle.py`, `preprocessing/generate_paired_smg_otherclass_bundle.py`, `preprocessing/make_signer_grid.py`, `preprocessing/make_kshot_signer_bundle.py` |
| BdSLW401 | `python preprocessing/extract_pose_cache.py --root /path/to/BdSLW401/Front --cache-dir data/bdslw401_pose_cache_front`, then `preprocessing/bundle_bdslw401_pose_to_npy.py` and `preprocessing/make_w401_sdval_bundle.py --val-signer 15` |
| AUTSL, ASL Citizen | `preprocessing/generate_autsl_split_npy.py`, `preprocessing/make_autsl_random_split.py`, `preprocessing/generate_aslcitizen_split_npy.py`, `preprocessing/generate_aslcitizen_mixed_split.py` |
| SSL pre-training pool | `preprocessing/build_ssl_pool_manifest.py`, then `preprocessing/compute_pretrain_targets.py --feature-mode pose_motion` |

The LOSO and signer-mixed clip lists used in the paper are in `splits/loso/` and
`splits/signer_mixed/` (BdSLW401: `splits/bdslw401/`).

## Quick start

```bash
# train + validate one configuration (best checkpoint selected on validation signer 15)
python main.py --config config/bdsl_block_gcn_si_lr01.yaml --seed 0 -Experiment_name bdsl_block_gcn_si_lr01_seed0

# score that checkpoint on the held-out TEST signers
python main.py --config config/bdsl_block_gcn_si_lr01_test.yaml --phase test --seed 0 \
    --weights work_dir/bdsl_block_gcn_si_lr01_seed0/bdsl_block_gcn_si_lr01_seed0_model-best.pt \
    -Experiment_name bdsl_block_gcn_si_lr01_seed0_test

# three seeds, resumable
python tools/run_multiseed.py --config experiments_si.yaml --seeds 0 1 2 --skip-existing
python tools/run_resumable_seed.py --config config/bdsl_block_gcn_si_lr01.yaml --seed 0 \
    --exp bdsl_block_gcn_si_lr01_seed0 \
    --test-config config/bdsl_block_gcn_si_lr01_test.yaml --test-exp bdsl_block_gcn_si_lr01_seed0_test

# leave-one-signer-out (re-bundles each fold from the pose cache)
python tools/run_loso.py --single config/bdsl_block_gcn_si_lr01.yaml --seeds 0 1 2

# aggregate seeds / folds
python tools/summarize_seeds.py --csv results_final.csv --markdown
```

Every run writes its resolved configuration to `work_dir/<experiment>/config.yaml`, per-epoch
score dumps to `work_dir/<experiment>/eval_results/`, and appends one row per evaluation to
`results_final.csv`. Configurations are YAML files whose `model:` and `feeder:` entries are
dotted import paths (e.g. `model.block_gcn.Model`, `feeders.feeder.Feeder`). All models take
`(N, C, T, V, M)` input. SLURM launchers and the per-program task lists are in `scripts/hpc/`
(see its README); `scripts/run_tasks_local.sh` runs a task list without SLURM.

## Reproducing the paper tables

```bash
make tables-check          # = python tools/p2_make_tables.py --check
make tables                # write the fragments to results/tables/generated/
make tables-provenance     # print the source file of every cell
make figures               # results/figures/*.pdf
```

`--check` regenerates every table fragment and diffs it cell by cell against the published
fragments in `results/tables/reference/` (exit status 0 = identical). It runs without data:
values whose raw source is a per-clip score dump under `work_dir/` or a label file under `data/`
are read from `results/tables/resolved_sources.json`, which records every value the generator
resolved for the published tables; the run log (`results/results_final.csv`) and the result
files under `docs/` are read directly. The output states how many values came from each.
With the experiments re-run locally, `--no-cache` requires every source raw.

| Paper table | Fragment(s) | Sources |
|---|---|---|
| Main comparison (a), pose rows | `tab_arch_a_pose` | run log, TEST score dumps, `docs/blockgcn_lr01_switch/raw/`, `docs/loso_heldout/<arch>.csv` |
| Main comparison (a), RGB / foundation / prior methods | `tab_arch_a_rgb`, `tab_arch_a_foundation`, `tab_arch_a_prior_rerun`, `tab_arch_a_prior_reported` | `docs/baselines_rerun/*.json`, `docs/p2_rerun_fixes_2026-10/s3d_cluster_seeds.json`, `docs/p2_tables/manual_values.yaml` |
| Main comparison (b), BdSLW401 | `tab_arch_b_w401` | run log, W401 score dumps |
| Signer-Mixing Gap | `tab_smg8_rows` | as the pose rows |
| Efficiency | `tab_eff_rows` | `docs/p2_tables/manual_values.yaml` (cost), TEST |
| Metric suite | `tab_suite_rows` | TEST score dumps via `tools/p2_metric_suite.py` |
| Bone stream | `tab_bone_rows` | `docs/p2_missing_joint_fixes_2026-10/` score dumps |
| LOSO bootstrap, folds, variance | `tab_losoboot_rows`, `tab_losofolds_rows`, `tab_losovar_rows` | `docs/loso_heldout/`, `docs/loso_heldout/derived/variance_decomp_final_2026-10-22.txt` |
| Significance | `tab_sig_a_rows`, `tab_sig_b_rows` | `docs/loso_heldout/derived/arch_significance_final_2026-10-22.txt` (re-run: `python tools/arch_significance.py --lr0p1 --bestck --two-sided`, needs score dumps) |
| Signer-normalized recipe | `tab_signernorm_s1_rows`, `tab_signernorm_s2_rows`, `tab_signernorm_loso_rows` | `python tools/signernorm_make_tables.py` (needs score dumps and `data/bdsl_si/test_label.pkl`; published output in `docs/signernorm_2026-10/generated/`) |

Values reported in the text and in the remaining tables (cross-dataset, cues, paired SMG,
signer diversity, test-time adaptation, GRL) are documented, with the runs that produced them,
in the program notes under `docs/` (index: `docs/README.md`). `results/run_manifest.csv` gives
the config, seed, scored checkpoint and argument overrides of every run the tables read, and
`scripts/hpc/<program>/tasks_*.txt` give the exact commands of each program.

## Signer-normalized recipe

`feeders/feeder_signernorm.py` (`SignerNormFeeder`) changes only the input; models are unchanged
apart from `in_channels` 3 → 5 when the hand-local channels are on. With every option off it
returns exactly what `feeders/feeder.py` returns (tested in `tests/test_feeder_signernorm.py`).

| Component | Config keys | Effect |
|---|---|---|
| ctr | `body_frame: True, body_scale: none` | per-frame shoulder-midpoint centring; padding and undetected joints stay 0 |
| a | `body_frame: True` | ctr + scaling by shoulder width |
| b | `hand_local: True` | 2 extra channels: wrist-relative hand coordinates divided by palm size |
| c | `random_mirror: True` | left/right mirroring at training time (`flip_index`, x → 1 − x) |
| d | `bone_aug: signer` | bone-length retargeting to another training signer (not adopted) |

The adopted recipe is +a+b+c (`config/signernorm/*_sn_abc*.yaml`; other architectures in
`config/signernorm/stage2/`, LOSO folds in `config/signernorm/loso/`). Configs reference the
feeder as `feeders_signernorm.SignerNormFeeder` (repository-root import shim). Details,
ablations and the selection disclosure: `docs/signernorm_2026-10/README.md`.

```bash
python tools/run_resumable_seed.py --config config/signernorm/bdsl_block_gcn_si_lr01_sn_abc.yaml --seed 0 \
    --exp bdsl_block_gcn_si_lr01_sn_abc_seed0 \
    --test-config config/signernorm/bdsl_block_gcn_si_lr01_sn_abc_test.yaml \
    --test-exp bdsl_block_gcn_si_lr01_sn_abc_seed0_test
```

## Integrity checks

| Check | Command |
|---|---|
| A run counts only if it reached its final epoch (checkpoints are pruned, so a `model-best.pt` proves nothing) | `python tools/check_run_complete.py work_dir/<run> [...]`; every run feeding the tables: `--p2-sweep`; LOSO coverage: `--loso-csv docs/loso_heldout/<arch>.csv` |
| Skeleton geometry of a pose corpus (body/hand slots, left/right) | `python tools/check_pose_geometry.py --npz-dir <cache> --strict` (or `--npy <bundle>`) |
| Missing joints are stored as (0, 0): mask them before derived quantities | `preprocessing/generate_bone_data_masked.py`, `preprocessing/make_cue_bundle_masked.py`, `tools/decodability_probe_v2.py` |
| Held-out LOSO scoring refuses incomplete folds | `python tools/loso_heldout_eval.py <arch>` |
| Repository integrity (configs, model classes, registries) | `python tools/validate_project.py` |
| Unit and smoke tests (CPU, no data) | `make test` |

Checkpoints and hyper-parameters are selected on validation and reported on TEST; significance
tests are two-sided with Holm correction.

## Project structure

```
.
├── main.py                  train / evaluate one config (YAML -> argparse, dotted-path loading)
├── main_signer_adv.py       BlockGCN + gradient-reversal signer adversary (GRL)
├── main_pretrain.py         masked pose SSL pre-training (SHuBERT-style)
├── feeders_signernorm.py    import shim for the signer-normalized feeder
├── experiments_si*.yaml     sweep registries for tools/run_multiseed.py / run_loso.py
├── config/                  run configs (lr01_switch/, lr0p1_switch/, lrsweep/, p2_mjfix/,
│                            p2_rerun_fixes/, signernorm/, w401_sdval_div/)
├── model/                   pose architectures, signer adversary, SSL wrapper
├── feeders/                 skeleton feeders (base + signer-normalized)
├── graph/                   27-node skeleton graph
├── preprocessing/           pose extraction, split definitions, bundlers
├── rgb_baseline/            S3D / I3D / VideoMAE baselines
├── tools/                   runners, completeness/geometry checks, statistics, table and figure
│   └── p2_analysis/         generators, per-signer analyses
├── splits/                  canonical, LOSO and signer-mixed split definitions
├── results/                 run log, run manifest, resolved-source cache, reference tables
├── docs/                    datasheet, program notes, held-out LOSO results
├── metadata/                Croissant 1.0 + RAI files of the derived pose releases
├── scripts/                 SLURM launchers and task lists (hpc/), local task runner
└── tests/                   CPU unit and smoke tests
```

Development: `make check` runs lint (ruff), tests, repository validation and the table check,
as CI does (`.github/workflows/ci.yml`). See `CONTRIBUTING.md`.
